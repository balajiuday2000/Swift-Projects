**Budgetly**

A SwiftUI based expense-sharing application that enables users to create trips, track shared expenses, customize bill splits and attach receipt images for every transaction. The app uses Core Data for local persistence and supports email reminders to help participants settle outstanding balances. It was tested extensively through TestFlight across multiple screen sizes before being deployed to the App Store.
